Installer SkanFact

Installer sur Mac

  1. Ouvrez le fichier .dmg téléchargé.
  2. Glissez SkanFact dans le dossier Applications.
  3. Au premier lancement, macOS demande une confirmation : clic droit sur l'application → Ouvrir → Ouvrir. C'est à faire une seule fois.
  4. L'assistant vous demande votre société, puis vous pouvez commencer.

Installer sur Windows

  1. Lancez le fichier .exe téléchargé.
  2. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires → Exécuter quand même.
  3. Suivez l'installateur : il crée les raccourcis Bureau et menu Démarrer.
  4. L'assistant vous demande votre société, puis vous pouvez commencer.

Ces avertissements viennent de l'absence de certificat de signature, pas d'un problème dans l'application. La signature Apple et Windows est prévue.

Pour ceux qui veulent voir venir

Il existe un canal d'essai, et il ne vous est pas proposé par hasard.

Les versions que vous téléchargez ici sont les versions stables. À côté, un canal bêta reçoit les versions d'essai avant qu'elles ne soient confirmées. Il est décoché à l'installation : vous ne recevrez jamais une version d'essai sans l'avoir demandée.

Où il se coche

Dans l'application, Paramètres → Mises à jour. Une question vous rappelle d'abord qu'une bêta s'installe par-dessus votre vraie comptabilité.

Ce qui est pris avant

Une sauvegarde nommée avant-beta est écrite sur le disque avant que le canal ne s'arme — pas au moment de l'installation, où il serait trop tard.

Comment on revient

On décoche, et la stable suivante réinstalle par-dessus. Sans question, sans perte : revenir en arrière ne doit jamais être plus difficile qu'avancer.

Si vous hésitez, ne cochez rien : la stable est le bon choix pour facturer et pour tenir des dossiers de clients.

Bon à savoir avant d'installer.

Que se passe-t-il après les 30 jours ?

La création de nouvelles pièces s'arrête. Tout le reste continue : lire, imprimer, exporter, sauvegarder, envoyer le dossier à votre comptable. Vos données ne sont jamais retenues.

Faut-il désinstaller une ancienne version ?

Non. L'installation remplace l'ancienne version et conserve vos données, qui sont rangées ailleurs. L'application vérifie ensuite toute seule s'il existe une version plus récente.

Combien pèse l'application ?

Environ 100 Mo sur Windows et 220 Mo sur Mac (la version Mac contient les deux processeurs, Intel et Apple Silicon).

Puis-je l'installer sur deux ordinateurs ?

Oui. La clé de licence est rattachée au matricule fiscal de votre société, pas à une machine : elle s'active sur vos postes, et refuse de s'activer sur le dossier d'une autre société. Le partage d'un même dossier à deux — chacun à son tour, via iCloud, OneDrive, un disque réseau ou une clé USB — demande l'offre Entreprise, et il est ouvert pendant l'essai.

Toutes les versions et leurs nouveautés sont publiées sur la page des versions.
